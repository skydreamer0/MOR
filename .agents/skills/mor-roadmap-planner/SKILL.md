# MOR Roadmap Planner

Read `AGENTS.md`, `ROADMAP.md`, and only relevant active docs in `docs/workflows/` or `infrastructure/`.

Produce concise plans with:

- Goal.
- Small tasks in recommended order.
- In/out of scope.
- Files likely affected.
- Verification commands.

Do not implement code in this skill. Keep the plan small enough for one task at a time.
