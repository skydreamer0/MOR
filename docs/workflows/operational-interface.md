# MOR 多頁營運介面

## 目的

MOR 的主介面分成四個營運頁面，讓總覽、跳單監控、預估調整、資料設定各自有清楚任務，不再全部塞在同一張大型表格。

## 頁面

| 路徑 | 頁面 | 用途 |
| --- | --- | --- |
| `/` | 業績總覽 Dashboard | 快速看本月金額目標、目前金額實績、預估月底金額、金額達成率、金額 GAP、高風險品項與高風險客戶。 |
| `/monitor/products` | 產品跳單監控 | 每天檢查低於去年同期的客戶品項組合，並查看追蹤備註。 |
| `/forecast` | 預估調整 | 保留原本的人工調整、備註、草稿、定稿與 Excel 匯出流程。 |
| `/settings` | 系統設定 / 資料檢核 | 管理品項排除、納入預算、顯示狀態，並檢查訂單與預算資料。 |

`/items` 保留相容入口，會導向 `/settings`。

## 計算規則

- Dashboard 整體總覽只顯示金額；數量只用於產品監控、預估調整與品項分析。
- 預算金額優先使用預算檔 `04預算總額`；只有舊資料沒有金額欄位時才暫以預算數量 * 最新單價估算。
- 目前實績金額與預估月底金額優先使用 `04預算總額 / 07預算S總量` 的同口徑金額單位估算，避免 S量乘包裝單價造成失真。
- 產品與品項視角的預算數量使用與預估明細 `銷+贈S量` 同口徑的 `07預算S總量`；`02預算總量` 保留為總量口徑。
- Dashboard 達成率與 GAP 只納入有預算目標的列；缺預算列保留在資料檢核，不放大分子。
- 達成率 = 預估月底數量 / 預算目標數量 * 100。
- 業績 GAP = 預估月底數量 - 預算目標數量。
- 金額 GAP = 預估月底金額 - 預算目標金額。
- 產品跳單高風險 = 預估月底數量低於去年同期數量 10% 以上。
- 跳單差異數量 = 預估月底數量 - 去年同期數量。

## 跳單狀態

| 狀態 | 規則 |
| --- | --- |
| 高風險 | 去年同期數量 > 0，且預估月底數量 < 去年同期數量 * 0.9 |
| 輕微下滑 | 去年同期數量 > 0，且預估月底數量低於去年同期但未達 10% |
| 正常/成長 | 去年同期數量 > 0，且預估月底數量大於等於去年同期 |
| 無去年同期 | 去年同期數量為 0 |

## 資料檢核

系統設定頁會顯示：

- 訂單資料筆數與日期範圍。
- 已匯入預算月份數。
- 缺預算列數。
- 單價為 0 的列數。
- 無去年同期的列數。

品項合併設定、商品號對應、客戶名稱對應目前標示為待建，不新增資料表或可編輯模型。
