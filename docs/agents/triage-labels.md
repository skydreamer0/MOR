# Triage Labels

This file maps the canonical Matt Pocock triage roles to labels used in this repo.

| Canonical role | Label in this repo | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate |
| `needs-info` | `needs-info` | Waiting on reporter details |
| `ready-for-agent` | `ready-for-agent` | Fully specified and AFK-agent ready |
| `ready-for-human` | `ready-for-human` | Needs human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

If label names change later, update the right-hand column.
